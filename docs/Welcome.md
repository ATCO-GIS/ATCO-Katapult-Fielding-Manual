# ATCO Katapult Fielding Manual

Welcome to the ATCO Katapult Fielding Manual. This site serves as a centralized reference for field collection procedures, standards, and best practices when using Katapult Pro.

The manual is intended to support consistent, accurate, and efficient data collection across all projects. Topics covered throughout the manual include:

- Mobile interface navigation
- Offline job management
- Midspan data collection
- Pole data collection standards
- Height photo best practices
- Crew responsibilities and communication
- Safety considerations during fielding

The **Manual** tab on the left contains instructions on how to use each of Katapults features for fielding as well as best practices and general information to know when fielding.

The **Additional Resources** tab on the left contains additional reference material, training videos, and helpful links related to field collection workflows.

Use the navigation panel on the left side of the site to move between the **Welcome page**, **Manual**, and **Additional Resources**, or use the search bar to quickly locate specific topics and procedures.

If you are looking for specific information located in the **Manual** you can use either the search bar in the top right, or the Table of Contents on the right side to quickly navigate to the information you need.

*Following the standards outlined in this manual will help improve data quality, reduce rework, and support efficient project completion.*
